# Story 05-7 — Biblioteca content library UI

## Context

The content library (`app/(protected)/biblioteca/`) is where mentees access video lessons and resources. The grid layout, content cards, video player, and filter/search components need a design pass aligned with the forest theme. The library currently has functional implementation from Epic 03; this story applies visual finishing.

## Acceptance Criteria

- [x] AC1: Content grid uses asymmetric or variable-width layout — NOT 3 equal columns (this pattern is banned in DESIGN.md)
- [x] AC2: Content cards display: thumbnail (Bunny CDN), title, type badge (video/document/template), and duration — clear visual hierarchy
- [x] AC3: Video player has loading state with skeleton matching player dimensions — no circular spinner
- [x] AC4: Filter/search is functional — at minimum: search by title, filter by content type; results update without full page reload
- [x] AC5: `npm run build` passes without type errors

## File List

- `apps/plataforma-runa/app/(protected)/biblioteca/page.tsx` — updated: uses BibliotecaClient, removed inline grid
- `apps/plataforma-runa/app/(protected)/biblioteca/[slug]/loading.tsx` — created: player skeleton (aspect-video, no spinner)
- `apps/plataforma-runa/components/biblioteca/BibliotecaClient.tsx` — created: search + type filter + asymmetric grid
- `apps/plataforma-runa/components/biblioteca/content-card.tsx` — rewritten: thumbnail, type badge, duration, h-full
- `apps/plataforma-runa/components/biblioteca/locked-card.tsx` — rewritten: matches ContentCard layout + blur overlay
- `apps/plataforma-runa/lib/types/content.ts` — updated: added duration_minutes? and thumbnail_url? optional fields

## Dev Notes

- Grid: consider `grid-cols-2 md:grid-cols-3` with one featured item spanning 2 columns — asymmetric
- Thumbnail: use Bunny CDN URLs; show a dark placeholder matching forest surface-2 while loading
- Player: Bunny Stream embed or native `<video>` with styled controls — match forest palette
- Type badge: small pill — `bg-accent text-text text-xs` — positioned top-right of thumbnail
- Duration: `font-mono text-muted` — monospace for consistent number alignment
