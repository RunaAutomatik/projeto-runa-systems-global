# Story 04-7 — Stripe — Checkout Session + /planos + /pagamento/sucesso

## Context

Creates the Stripe payment loop entry point. When a visitor clicks "Comprar RUNA" on `/planos`, they are sent to a Stripe-hosted Checkout page. After successful payment, they land on `/pagamento/sucesso`.

The actual tier upgrade (Supabase + Clerk sync) happens in Story 04-8 via webhook. This story only creates the Checkout Session and the confirmation page.

Product: RUNA — R$ 7.000 / 21 sessões / 7 semanas. Launch coupon `LANCA2026` gives ~R$ 3.000 discount.

## Acceptance Criteria

- [x] `POST /api/checkout` creates a Stripe Checkout Session and returns `{ url }`
- [x] Checkout Session config:
  - `mode: 'payment'`
  - `line_items: [{ price: STRIPE_PRICE_ID_MENTORIA, quantity: 1 }]`
  - `allow_promotion_codes: true` (enables LANCA2026 coupon at checkout)
  - `success_url: ${NEXT_PUBLIC_APP_URL}/pagamento/sucesso?session_id={CHECKOUT_SESSION_ID}`
  - `cancel_url: ${NEXT_PUBLIC_APP_URL}/planos`
  - `metadata: { clerk_user_id: userId }`
- [x] Unauthenticated users hitting `/api/checkout` are redirected to `/entrar?redirect_url=/planos`
- [x] `/planos` page "Comprar RUNA" button (already exists from Story 02-5) calls `POST /api/checkout` and redirects to the Stripe URL
- [x] `/pagamento/sucesso` page:
  - Verifies `session_id` query param via `stripe.checkout.sessions.retrieve(sessionId)`
  - Shows "Pagamento confirmado!" if `payment_status === 'paid'`
  - Shows "Seu acesso será ativado em alguns minutos." (webhook async delay disclosure)
  - Shows link: "Acessar plataforma →" to `/mentorados/[menteeSlug]` (available after webhook fires)
  - Shows fallback message if `session_id` is missing or payment not confirmed
- [x] Stripe publishable key used in client: `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`
- [x] Stripe secret key used server-side only: `STRIPE_SECRET_KEY`
- [x] `npm run build` passes with no TypeScript errors
- [x] `npm run lint` passes

## Dev Notes

- Install: `npm install stripe @stripe/stripe-js`
- Stripe client init: `new Stripe(process.env.STRIPE_SECRET_KEY!, { apiVersion: '2024-12-18.acacia' })`
- The `/pagamento/sucesso` page should handle the case where the webhook hasn't fired yet — the mentee slug won't exist in Supabase yet. Show a "aguardando ativação" message instead of a broken link
- `metadata.clerk_user_id` is the critical field that Story 04-8 uses to perform the 3-way sync
- `/api/checkout` requires authentication — use `const { userId } = await auth()` from Clerk
