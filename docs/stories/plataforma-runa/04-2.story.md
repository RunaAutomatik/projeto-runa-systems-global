# Story 04-2 — Admin — /admin/mentorados mentee table

## Context

Arthur needs a single view of all mentees to manage sessions and track progress. This page lists every `profiles` row with `tier = 'mentee'` in a table with key metadata derived from the `sessions` table.

The page is a Server Component — all queries run server-side. No client-side state needed for the table itself. Clicking a row navigates to `04-3` (`/admin/mentorados/[id]`).

## Acceptance Criteria

- [x] Route `/admin/mentorados` renders a table of all profiles where `tier = 'mentee'`
- [x] Table columns: Nome, Email, Sessões completadas, Próxima sessão, Tier badge, Link "Gerenciar"
- [x] "Sessões completadas" = count of `sessions` rows for that mentee where `bunny_video_id IS NOT NULL` (video uploaded = completed session)
- [x] "Próxima sessão" = the lowest `session_number` session for that mentee where `bunny_video_id IS NULL` and `session_date IS NOT NULL` — shows the date; shows "—" if none scheduled
- [x] Tier badge: `mentee` → `<span>` with `bg-accent text-textPrimary text-xs`
- [x] "Gerenciar" link navigates to `/admin/mentorados/[id]` (using `profiles.id`)
- [x] Empty state when no mentees exist: "Nenhum mentorado ativo. Configure o Stripe para aceitar pagamentos." with link to `/planos`
- [x] Page title: "Mentorados" with subtitle showing count "N mentorado(s) ativo(s)"
- [x] `npm run build` passes with no TypeScript errors
- [x] `npm run lint` passes

## Dev Notes

- Use a single Supabase query with join to avoid N+1: `profiles` left join `sessions` on `sessions.mentee_id = profiles.id`
- Group/aggregate in the query: `count(sessions.id)`, `min(sessions.session_number) FILTER (WHERE bunny_video_id IS NULL)`
- Alternatively, fetch profiles then sessions in two queries and merge in TS — either approach acceptable
- This is a read-only view. CRUD operations are in Story 04-3
