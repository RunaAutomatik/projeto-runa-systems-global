# Story 04-1 — Admin dashboard — real data + active nav state

## Context

The admin shell already exists: `app/admin/layout.tsx` (auth gate + redirect) and `app/admin/page.tsx` (3 StatCards with `"—"` values). The `AdminSidebar` has nav links but no active state.

This story wires real Supabase data to the dashboard cards and adds active link highlighting to the sidebar. It is the minimal Epic 04 deliverable that unblocks Story 04-10 (Lucas Pesto data visible in the platform).

No new routes are created here. 04-2 and 04-3 create the mentee management routes.

## Acceptance Criteria

- [x] `/admin` StatCard "Mentorados ativos" shows count of `profiles` rows where `tier = 'mentee'`
- [x] `/admin` StatCard "Sessões este mês" shows count of `sessions` rows where `session_date` is in the current calendar month
- [x] `/admin` StatCard "Receita total" shows `R$ —` with a note "integração Stripe — Story 04-7" (placeholder — Stripe not yet configured)
- [x] `AdminSidebar` highlights the active route using Next.js `usePathname()`
- [x] Active nav item: `text-textPrimary bg-surface2` classes applied
- [x] Inactive nav items retain: `text-textMuted hover:text-textPrimary hover:bg-surface2`
- [x] Supabase queries use service role key (server component — no RLS bypass needed for admin)
- [x] `npm run build` passes with no TypeScript errors
- [x] `npm run lint` passes

## File List

- `apps/plataforma-runa/app/admin/page.tsx` (modify — wire Supabase queries)
- `apps/plataforma-runa/components/admin/admin-sidebar.tsx` (modify — add active state with `usePathname`)

## Dev Notes

- `app/admin/page.tsx` is currently a Server Component — keep it as Server Component, fetch data at top level
- `AdminSidebar` must become a Client Component (`"use client"`) to use `usePathname()`
- Supabase admin client: `createClient(url, serviceRoleKey)` — already established pattern from seed scripts
- Month filter: `session_date >= date_trunc('month', now()) AND session_date < date_trunc('month', now()) + interval '1 month'`
- Risk: `SUPABASE_SERVICE_ROLE_KEY` must be present in `apps/plataforma-runa/.env.local` — verify before implementing; if absent, Supabase admin client will silently fail or throw
