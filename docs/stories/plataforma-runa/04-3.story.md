# Story 04-3 — Admin — /admin/mentorados/[id] mentee management

## Context

The core admin page for managing an individual mentee. Arthur uses this to: upload session deliverables, mark sessions as complete (video present), add private notes, and review the full session/deliverable history.

The `[id]` param is `profiles.id` (Clerk user ID). This page mixes Server Components (initial data fetch) with Client Components (notes textarea, mark-complete button).

## Acceptance Criteria

- [x] Route `/admin/mentorados/[id]` renders for a valid mentee ID; redirects to `/admin/mentorados` if ID not found or tier ≠ 'mentee'
- [x] Page header: mentee name (from `profiles.email` until name field added), tier badge, mentee slug
- [x] **Sessions list**: table showing all sessions ordered by `session_number` with: number, title, date, duration, video status (✓ uploaded / ○ pending), link to mentee-facing session page
- [x] **Mark session complete**: button on each session row → opens inline form to set `title`, `session_date`, `duration_minutes`, `summary` — saves via `PATCH /api/admin/sessions/[sessionId]`
- [x] **Deliverables list**: table showing all deliverables for this mentee with: title, type badge, linked session, date
- [x] **Add deliverable**: form with fields `title`, `type` (select: prompt/template/workflow/agent/doc), `session_id` (optional select from mentee sessions), `file_url` (optional), `description` (optional) — saves via `POST /api/admin/deliverables`
- [x] **Notes**: textarea bound to `profiles.mentee_context.notes` — auto-saves on blur via `PATCH /api/admin/mentees/[id]/notes`
- [x] All mutations return 200 on success and refresh the relevant section (router.refresh() or revalidatePath)
- [x] API routes enforce admin auth: `userId !== ARTHUR_CLERK_USER_ID → 403`
- [x] `npm run build` passes with no TypeScript errors
- [x] `npm run lint` passes

## API Routes

```typescript
// PATCH /api/admin/sessions/[sessionId]
// Body: { title?, session_date?, duration_minutes?, summary?, bunny_video_id? }

// POST /api/admin/deliverables
// Body: { mentee_id, title, type, session_id?, file_url?, description? }
// Returns: new deliverable row

// PATCH /api/admin/mentees/[id]/notes
// Body: { notes: string }
// Merges into profiles.mentee_context jsonb: { ...existing, notes }
// Returns: { ok: true }
```

## Dev Notes

- Notes merge pattern for jsonb: `UPDATE profiles SET mentee_context = mentee_context || '{"notes": "..."}'::jsonb WHERE id = $1`
- All API routes must check `const { userId } = await auth(); if (userId !== process.env.ARTHUR_CLERK_USER_ID) return NextResponse.json({}, { status: 403 })`
- Session "mark complete" does NOT upload the video — that is Story 04-4. It only sets metadata fields
- The video upload button lives here but triggers the 04-4 Bunny upload component
