# Story 05-5 — Mentee dashboard (MENTI) UI — tema forest

## Context

The protected mentee area (`app/(protected)/`) must use the `forest` dark theme throughout — architectural, precise, never warm or casual. The dashboard is the primary interface mentees use to track sessions, access content, and monitor progress. All states (loading, empty, error) must be designed — no bare "no data" text.

## Acceptance Criteria

- [x] AC1: All protected routes (`app/(protected)/`) use `tema forest` consistently — `var(--bg)` resolves to `#080C09`, surface-1 to `#111712`
- [x] AC2: Navigation sidebar with sections: Sessões, Biblioteca, Progresso — clearly labeled, active state visible
- [x] AC3: Session cards render three states: **futura** (upcoming — locked appearance), **disponível** (available — actionable CTA), **concluída** (completed — muted/checkmark)
- [x] AC4: Empty states for all list views — composed composition indicating how to populate data (not just "sem dados" text)
- [x] AC5: Loading states use skeleton loaders matching exact layout dimensions — NO generic circular spinners
- [x] AC6: `npm run build` passes without type errors

## File List

- `apps/plataforma-runa/app/(protected)/dashboard/` — mentee home
- `apps/plataforma-runa/app/(protected)/sessoes/` — session list + detail
- `apps/plataforma-runa/app/(protected)/progresso/` — progress view
- `apps/plataforma-runa/components/mentee/` — mentee-specific UI components
- `apps/plataforma-runa/components/ui/skeleton.tsx` — skeleton loader (if not already exists)

## Dev Notes

- Read DESIGN.md before implementing — source of truth for forest theme tokens
- Forest: bg `#080C09`, surface-1 `#111712`, surface-2 `#1A201B`, border `#2A342C`, text `#E8EDE9`, muted `#7A8C7C`, accent `#3D4842`
- Typography: Geist Sans headings + Geist Mono for session numbers/data
- Skeleton loaders: use `animate-pulse` + matching `bg-surface-2` backgrounds
- Empty states: include a brief instructional message and an illustration or icon composition
- Cards use `rounded-2xl` and diffused shadow tinted to background hue — no neon glows
