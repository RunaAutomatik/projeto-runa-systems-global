# Story 04-5 — Admin — Scripted intake form (one-question-at-a-time)

## Context

Arthur uses this form to collect structured onboarding information from new mentees before Session 01. The form asks 7 business questions (from the ORION `*runa-intake` protocol) and 4 Four Cs questions, one at a time.

The form can be sent to the mentee as a link or completed by Arthur during a discovery call. Answers are saved to `profiles.mentee_context` jsonb. There is no LLM involved — pure React state stepping through a question array.

## Acceptance Criteria

- [x] Route `/admin/mentorados/[id]/intake` renders the scripted intake form
- [x] Form presents ONE question at a time with a textarea answer field
- [x] 7 business questions in order:
  1. "Qual é o principal produto/serviço que você vende hoje?"
  2. "Qual é a maior dificuldade no seu processo comercial?"
  3. "Quantas horas por semana você gasta em tarefas operacionais?"
  4. "Você já usa alguma ferramenta de IA no seu negócio? Qual?"
  5. "Qual é a meta de faturamento para os próximos 90 dias?"
  6. "Você tem equipe? Quantas pessoas?"
  7. "O que você espera que mude na sua operação depois da RUNA?"
- [x] 4 Four Cs questions follow the 7 business questions (8–11):
  8. "Capacidade: qual é sua disponibilidade real por semana para implementar mudanças?"
  9. "Capital: você tem recurso para investir em ferramentas e automações?"
  10. "Comprometimento: como você avalia seu nível de comprometimento com a transformação?"
  11. "Clareza: você tem clareza sobre o que precisa mudar primeiro no seu negócio?"
- [x] Progress indicator: "Pergunta N de 11" visible at all times
- [x] "Próxima" button advances to next question (disabled if answer is empty)
- [x] "Anterior" button returns to previous question (answers preserved)
- [x] On question 11 completion: "Enviar" button appears
- [x] Submit calls `PATCH /api/admin/mentees/[id]/intake` with all 11 answers
- [x] `PATCH /api/admin/mentees/[id]/intake` merges answers into `profiles.mentee_context`:
  ```json
  { "intake": { "q1": "...", "q2": "...", ..., "q11": "...", "completed_at": "ISO" } }
  ```
- [x] After submit: shows "Intake concluído!" confirmation + link back to `/admin/mentorados/[id]`
- [ ] If intake already completed: shows "Intake já realizado em [date]" with option to redo
- [x] `npm run build` passes with no TypeScript errors
- [x] `npm run lint` passes

## Dev Notes

- The question array should be a constant defined at module level — easy to extend
- Use `useState<string[]>` initialized to `new Array(11).fill('')` for answers
- Use `useState<number>` for `currentIndex` (0-based)
- `PATCH /api/admin/mentees/[id]/intake`: validate userId = ARTHUR_CLERK_USER_ID, then update jsonb
- The Four Cs label prefix should be visible in the question text itself (as defined above) — no separate UI needed for the label
- This intake can also be sent as a public link in the future (separate story) — design accordingly with the state stored server-side
