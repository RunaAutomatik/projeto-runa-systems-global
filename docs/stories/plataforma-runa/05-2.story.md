# Story 05-2 — Tailwind config + CSS design tokens

## Context

With DESIGN.md in place (05-1), the CSS custom properties and Tailwind semantic color mapping must be implemented. This is the infrastructure layer that allows all subsequent UI stories (05-4 through 05-8) to use theme-aware classes. Both themes must be encoded in `globals.css` and both fonts installed.

## Acceptance Criteria

- [x] AC1: `tailwind.config.ts` maps all semantic color names to CSS vars — `bg: 'var(--bg)'`, `surface-1: 'var(--surface-1)'`, `surface-2: 'var(--surface-2)'`, `border: 'var(--border)'`, `text: 'var(--text)'`, `muted: 'var(--muted)'`, `accent: 'var(--accent)'`
- [x] AC2: `globals.css` defines `.theme-forest` with all custom properties: `--bg: #080C09`, `--surface-1: #111712`, `--surface-2: #1A201B`, `--border: #2A342C`, `--text: #E8EDE9`, `--muted: #7A8C7C`, `--accent: #3D4842`
- [x] AC3: `globals.css` defines `.theme-papel` with all custom properties: `--bg: #F8F5EF`, `--surface-1: #FFFFFF`, `--surface-2: #F0EDE6`, `--border: #D4CFC6`, `--text: #1A2219`, `--muted: #6B7280`, `--accent: #E8A13A`
- [x] AC4: Geist Sans + Geist Mono installed and configured via `next/font` for forest theme (admin/dashboard typography)
- [x] AC5: Outfit or Satoshi installed and configured via `next/font` for papel theme (landing page typography)
- [x] AC6: `npm run build` passes without type errors after changes

## File List

- `apps/plataforma-runa/tailwind.config.ts` — add CSS var color mapping
- `apps/plataforma-runa/app/globals.css` — add `.theme-forest` and `.theme-papel` blocks
- `apps/plataforma-runa/app/layout.tsx` — font configuration via next/font

## Dev Notes

- Use `extend.colors` in Tailwind config, not override — preserve existing utilities
- Forest: `font-family: var(Geist Sans), sans-serif` — use `next/font/google` or local font
- Papel: `font-family: var(Outfit), sans-serif` — can be Google Fonts via next/font
- Both themes must share the same CSS variable names (`--bg`, `--surface-1`, etc.) — only the values differ
- `Inter` is explicitly banned in DESIGN.md — do not install or reference it
