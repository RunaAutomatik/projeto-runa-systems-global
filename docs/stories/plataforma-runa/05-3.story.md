# Story 05-3 — ThemeProvider + theme toggle with FOUC prevention

## Context

Users must be able to switch between `forest` (dark) and `papel` (light/cream) themes. The toggle must persist across sessions and page reloads without Flash of Unstyled Content (FOUC). The server-side cookie approach ensures the correct theme class is injected on the `<html>` element before hydration. Clerk dark mode must match the forest theme.

## Acceptance Criteria

- [x] AC1: `ThemeContext` with `useTheme` hook exported from `components/theme-provider.tsx` (or equivalent path)
- [x] AC2: Theme toggle persists in both `localStorage` (client) and cookie `runa-theme` (server) — both must stay in sync on every toggle
- [x] AC3: `app/layout.tsx` reads `runa-theme` cookie server-side via `cookies()` and injects `className={`theme-${theme}`}` on `<html>` — default falls back to `'forest'`
- [x] AC4: `ClerkProvider` in `app/layout.tsx` has `appearance={{ baseTheme: dark, variables: { colorBackground: '#080C09', colorPrimary: '#3D4842' } }}` for forest theme
- [x] AC5: Theme toggle component renders correctly in both themes — no layout shift, no FOUC on reload
- [x] AC6: `npm run build` passes without type errors

## File List

- `apps/plataforma-runa/components/theme-provider.tsx` — ThemeContext + useTheme hook
- `apps/plataforma-runa/components/theme-toggle.tsx` — toggle component
- `apps/plataforma-runa/app/layout.tsx` — cookie read + html class injection + ClerkProvider appearance

## Dev Notes

- Import `{ cookies }` from `'next/headers'` in `app/layout.tsx` (server component)
- Cookie name: `runa-theme`, values: `'forest'` | `'papel'`
- `ClerkProvider` import for dark theme: `import { dark } from '@clerk/themes'`
- `ThemeProvider` must be a Client Component (`'use client'`) — cannot wrap server components directly; use children pattern
- FOUC fix: the cookie is read before React hydration, so the class is already on `<html>` when JS loads
