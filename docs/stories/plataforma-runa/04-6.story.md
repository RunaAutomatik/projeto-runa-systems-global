# Story 04-6 — Admin — /admin/conteudo content CMS

## Context

Arthur needs to add, edit, and publish content items (lessons, modules) without touching the database directly. Content items are stored in the `content_items` table (created in Story 02-1).

This story creates a simple CMS: a list view with status indicators and an add/edit form. No rich text editor needed — descriptions are plain text.

## Acceptance Criteria

- [x] Route `/admin/conteudo` renders a table of all `content_items` ordered by `created_at DESC`
- [x] Table columns: Título, Slug, Tier badge, Categoria, Status (published/draft — based on whether `bunny_video_id` is set), Data, Ações
- [x] "Adicionar conteúdo" button opens a slide-over or inline form
- [x] Add form fields: `title` (required), `slug` (auto-generated from title, editable), `description` (textarea), `bunny_video_id` (optional), `tier` (select: free/member/mentee), `category` (text input)
- [x] Slug auto-generation: `title.toLowerCase().replace(/\s+/g, '-').replace(/[^a-z0-9-]/g, '')` — updates as user types title, but is editable
- [x] Submit calls `POST /api/admin/content` → inserts into `content_items`
- [x] Edit: clicking a row opens the same form pre-populated — submit calls `PATCH /api/admin/content/[id]`
- [x] Delete: trash icon on each row → confirmation dialog → `DELETE /api/admin/content/[id]`
- [x] Slug uniqueness: API returns 409 if slug already exists; form shows "Slug já existe"
- [x] After add/edit/delete: list refreshes (router.refresh() or revalidatePath('/admin/conteudo'))
- [x] All API routes enforce admin auth: 403 if not ARTHUR_CLERK_USER_ID
- [x] `npm run build` passes with no TypeScript errors
- [x] `npm run lint` passes
