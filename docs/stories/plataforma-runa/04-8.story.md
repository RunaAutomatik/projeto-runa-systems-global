# Story 04-8 — Stripe webhook — 3-way sync (Supabase + Clerk + subscriptions)

## Context

**CRITICAL story** — this is the automation core of the payment loop. When a buyer completes checkout, Stripe sends a `checkout.session.completed` event to this webhook. The handler must atomically upgrade the user in 3 systems: Supabase (`profiles.tier`), Clerk (`publicMetadata.tier`), and the new `subscriptions` table.

The Clerk sync is critical: the middleware reads `publicMetadata.tier` to gate `/mentorados/*` routes without a database query on every request. If Clerk is out of sync, the user can't access the platform even though they paid.

A self-healing check runs on every authenticated request: if `publicMetadata.tier !== 'mentee'` but Supabase has `tier = 'mentee'`, the sync is forced. This covers webhook delivery delays.

## Migration SQL

```sql
CREATE TABLE subscriptions (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  mentee_id text NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  stripe_session_id text NOT NULL UNIQUE,
  stripe_payment_intent_id text,
  amount_cents integer NOT NULL,
  currency text DEFAULT 'brl',
  status text DEFAULT 'paid',
  created_at timestamptz DEFAULT now()
);

ALTER TABLE subscriptions ENABLE ROW LEVEL SECURITY;

CREATE POLICY "mentees view own subscription"
  ON subscriptions FOR SELECT
  USING (mentee_id = (SELECT id FROM profiles WHERE id = auth.uid()::uuid));
```

Note: `mentee_id` is `text` (NOT uuid) — `profiles.id` stores Clerk user IDs which are text strings.

## Dev Notes

- CRITICAL: Stripe webhook route must export `export const dynamic = 'force-dynamic'` and `export const config = { api: { bodyParser: false } }` — raw body required for signature verification
- In App Router, use `const rawBody = await request.text()` BEFORE any other body parsing
- Clerk `clerkClient` is from `@clerk/nextjs/server` — import as `import { clerkClient } from '@clerk/nextjs/server'`
- Slug utility: `email.split('@')[0].toLowerCase().replace(/[^a-z0-9]/g, '-').replace(/-+/g, '-')`
- Self-healing implementation: in `app/[mentee]/layout.tsx` or a shared auth check, compare Clerk metadata tier vs Supabase tier and sync if needed
- Stripe webhook secret is different from API key — set via Stripe dashboard → Webhooks → your endpoint → signing secret
