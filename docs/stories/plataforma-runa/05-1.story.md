# Story 05-1 — DESIGN.md dual-theme — forest + papel design system

## Context

Epic 05 begins the UI/UX finishing phase for the RUNA OS platform. Before any implementation starts, a single source-of-truth design document must be generated that encodes both themes: `forest` (dark — admin + mentee dashboard) and `papel` (light/cream — public landing page). Google Stitch is offline since 2026-05-16; the pipeline is: `taste-design skill → DESIGN.md → @dev implements → /impeccable audit`.

## Acceptance Criteria

- [x] AC1: `DESIGN.md` exists at `apps/plataforma-runa/DESIGN.md` with dedicated sections for both `forest` and `papel` themes
- [x] AC2: Forest theme fully documented — colors (`#080C09` bg, `#111712` surface-1, `#1A201B` surface-2, `#2A342C` border, `#E8EDE9` text, `#7A8C7C` muted, `#3D4842` accent), typography (Geist Sans + Geist Mono), component behaviors, motion philosophy
- [x] AC3: Papel theme fully documented — colors (`#F8F5EF` bg, `#FFFFFF` surface, `#1A2219` text, `#E8A13A` accent-warm amber, `#4ABFCC` accent-tech cyan), typography (Outfit/Satoshi + Geist Mono)
- [x] AC4: CSS custom properties pattern documented — `.theme-forest { --bg: #080C09; --surface-1: #111712; ... }` and `.theme-papel { ... }` with all semantic variables
- [x] AC5: Anti-patterns section explicitly bans: Inter font, neon/outer glows, 3-column equal card layouts, AI copywriting clichés, generic placeholders, fabricated data/metrics
- [x] AC6: Component behaviors documented for both themes (buttons, cards, inputs, loading skeletons, empty states)
- [x] AC7: Layout principles documented (asymmetric splits, max-width containment, no h-screen iOS fix)
- [x] AC8: Motion philosophy documented (spring physics `stiffness: 100, damping: 20`, staggered reveals, hardware-accelerated transforms only)
