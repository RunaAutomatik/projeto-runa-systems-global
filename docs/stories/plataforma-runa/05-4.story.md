# Story 05-4 — RUNA OS landing page UI — tema papel

## Context

The public landing page (`app/(public)/`) must adopt the `papel` theme and communicate the RUNA product value proposition. Design identity: Dear Alice / Chobani Solarpunk — warm cream background, amber + cyan accents, organic geometry, precision lines. The page must drive conversions to the R$ 7.000 RUNA product. Implement from DESIGN.md — no Google Stitch (offline since 2026-05-16).

## Acceptance Criteria

- [x] AC1: All public routes (`app/(public)/`) use `tema papel` consistently — `var(--bg)` resolves to `#F8F5EF`, text to `#1A2219`
- [x] AC2: Hero section has headline, subheadline, and primary CTA — no filler text ("Scroll to explore", scroll arrows, bouncing chevrons are banned)
- [x] AC3: Features/benefits section uses asymmetric layout — NOT 3 equal columns; use 2-column zig-zag, asymmetric grid, or horizontal scroll
- [x] AC4: Pricing section shows R$ 7.000 with clear CTA (checkout link or WhatsApp) and transformation statement
- [x] AC5: Footer with relevant links — no lorem ipsum, no placeholder names ("John Doe", "Acme")
- [x] AC6: No fabricated data or statistics — no "99.98% uptime", "50k users" invented metrics
- [x] AC7: `npm run build` passes without type errors

## Dev Notes

- Read DESIGN.md (generated in 05-1) before implementing — it is the source of truth
- Papel theme: bg `#F8F5EF`, accent-warm `#E8A13A` (amber), accent-tech `#4ABFCC` (cyan)
- Typography: Outfit/Satoshi headings + Geist Mono for data
- Hero: left-aligned or split-screen (centered hero is banned for high-variance projects)
- CTA: maximum ONE primary CTA per section — no "Learn more" secondary links
- Use `picsum.photos` or SVG avatars if placeholder images are needed — no broken Unsplash links
- Use `min-h-[100dvh]` for full-height sections — NEVER `h-screen` (iOS Safari bug)
