# MIND$ — Etapa 4 do Alicerce

> **Parte obrigatória do RUNA SYSTEMS** — não um módulo opcional pós-alicerce
> Etapa 4 da sequência canônica: Mapeamento → Claude Code → SQUAD$ → **MIND$**
> O cliente estrutura aqui a base de conhecimento que alimenta todos os agentes do negócio

## O Que é MIND$

A base de conhecimento é o cérebro compartilhado do squad. Sem ela, os agentes operam genéricos.
Com ela, cada agente sabe como a empresa pensa, vende, entrega e se posiciona.

MIND$ entrega o processo de extração e estruturação desse conhecimento em um vault Obsidian
que os agentes do SQUAD$ consultam via AKASHA.

## Metodologia

- **Framework Universal de Extração de Conhecimento** — processo em 3 fases para mapear expertise
- **Framework de Marca Digital** — extração de posicionamento, voz e identidade
- Vault de saída: estruturado no padrão AKASHA (ORION + wiki-self-heal)
