**1. `npx skills init` — ad-hoc, sem instalação**

Quando criar uma nova skill do zero, o comando scaffolda o `SKILL.md` com frontmatter correto:

```bash
npx skills init nome-da-skill
```

Uso único, sem overhead, sem dependência permanente. Gera o template base que já seguimos.

**2. `npx skills find` — exploração eventual**

Se em algum momento quiser ver o que a comunidade publicou para temas como SEO, n8n, Supabase, ou qualquer gap no stack:

```bash
npx skills find supabase
npx skills find n8n automation
```
