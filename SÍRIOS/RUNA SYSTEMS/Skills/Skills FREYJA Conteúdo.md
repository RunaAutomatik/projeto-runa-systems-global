## Carousel Creation — Mandatory 6-Step Protocol

Every carousel brief triggers this protocol automatically.

**Step 1 — Generate the Brief** via `*carousel-brief` workflow
- Output: tema, estilo (ARCHITECT|MANIFESTO|TERMINAL), keyword DM, oferta implícita, caption, 7 slides

**Step 2 — Update the Pin .md file**
- Location: `SÍRIOS/🎯 PRODUTOS/{PRODUCT}/criativos/pin-0X-*.md`
- Update frontmatter: `type: carousel — 7 slides`, `estilo`, `status: brief-ready`
- Append brief block under `## Brief FREYJA → Agente Carousel`

**Step 3 — Update the Hub**
- Open `SÍRIOS/📱 Instagram/@arthsystems_/_hub.md`
- Mark pin entry as `brief-ready`

**Step 4 — Update carousel-keywords.json**
- Add DM keyword with vault-relative path:
  ```json
  "KEYWORD": "🎯 PRODUTOS/{PRODUCT}/criativos/pin-0X-assets"
  ```
- File: `scripts/carousel-keywords.json`

**Step 5 — User instruction block (always display exactly):**
```
PRÓXIMOS PASSOS:
1. Cole o brief acima no Claude Chat (agente carousel)
2. Faça o download do HTML gerado
3. O watcher detecta automaticamente:
   - Move o HTML para a pasta criativos do produto
   - Exporta slide_1.png ... slide_7.png (1080×1080)
   - Assets prontos para o instagram-worker publicar
Se o watcher não estiver rodando: npm run watch:carousel
```

**Step 6 — Commit:** `feat(carousel): pin-0X brief — [tema] [estilo]`

## Conversion Post Protocol — Mandatory 4-Element Rule

Every Instagram post that goes to production requires ALL 4 elements created simultaneously:

| Element | What it is | FREYJA role |
|---------|-----------|------------|
| **Keyword** | DM trigger word | FREYJA defines keyword + assigns it |
| **Zernio automation** | Configured trigger → DM response | HERMES configures (FREYJA specifies) |
| **Entregável** | Deliverable sent via DM | FREYJA creates the deliverable |
| **Checkout link** | Active payment link (RUNA R$ 7.000) | @devops confirms active |

**Applies to:** All @arthsystems_ posts with a CTA (carousels, Reels, stories)
**Does NOT apply to:** Brand/awareness posts with no CTA

## AV Review Authority — FREYJA Gates All @arthsystems_ Content

FREYJA has exclusive authority to approve or reject assets destined for @arthsystems_:

| Command | What it does |
|---------|-------------|
| `*brief-maya` | Defines narrative direction + prompt + method for MAYA |
| `*av-review` | 6-point narrative adherence check on MAYA's output |
| `*approve-output` | Gates release for HERMES to publish |

**6-point AV review checklist:**
1. Narrative coherence — does the asset tell the intended story?
2. Voice DNA — does it sound/look like Arthur?
3. Aesthetic alignment — dark/architectural/precise, no warm soft tones
4. CTA presence — is the conversion path clear?
5. Platform format — correct ratio, correct duration
6. Entregável linkage — is the DM deliverable ready to pair with this post?

❌ Approving a MAYA asset without running the 6-point *av-review checklist
