# CLAUDE CODE — Etapa 2 do Alicerce

> **Parte obrigatória do RUNA SYSTEMS** — não um módulo opcional pós-alicerce
> Etapa 2 da sequência canônica: Mapeamento → **Claude Code** → SQUAD$ → MIND$
> Cobre S02 (†CODE I — Ambiente) e S03 (†CODE II — Fluxo)

| 1 | Mapeamento Neural | S01 | Mapeia processos e define a trilha personalizada |

## Os 3 Ambientes Claude

| Ambiente | Nome | Quando usar |
|----------|------|------------|
| Claude.ai chat | †CHAT | Thinking partner, co-criação estratégica |
| Claude.ai Projects | †COWORK | Projetos longos, contexto persistente |
| Claude Code (terminal) | †CODE | Execução agêntica, automações, squad |

> †CHAT e †COWORK são módulos de referência no Skool mas não são sessões obrigatórias do alicerce.

## S02 — †CODE I: Ambiente

- Instalação: Node.js → `npm install -g @anthropic-ai/claude-code`
- Ferramentas core: Read, Write, Edit, Bash, Grep, Glob
- Permission modes: Ask / Auto / Explore
- Primeiro teste: Claude Code lê e analisa um documento real do negócio

## S03 — †CODE II: Fluxo

- CLAUDE.md: sistema de instruções persistente (5 camadas)
- settings.json: configuração e hooks básicos
- Primeiro agente simples: persona + comandos + `@agent-name`
- Desafio: CLAUDE.md com 3 regras reais + agente ativo + 5 tarefas executadas
