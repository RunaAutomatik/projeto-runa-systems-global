# Mapeando Seu Negócio

> Módulo 1 · Aulas 1.1 e 1.2

Antes de construir qualquer agente, você precisa saber exatamente o que cada um vai fazer. Squads sem mapeamento se tornam caos organizado — agentes que duplicam trabalho, conflitam, ou cobrem funções que você não precisava automatizar.

Este documento tem dois worksheets: o mapeamento de funções e a matriz de delegação.

---

## Por que isso importa

Um squad é uma empresa. Empresas que crescem sem organograma são empresas que crescem com problemas.

Antes de contratar pessoas, boas empresas definem o escopo de cada função. O mesmo vale para agentes de IA. A diferença é que um agente mal definido não reclama — ele simplesmente produz output errado e você não sabe por quê.

## Worksheet 2 — Matriz de Delegação

Use os dados do Worksheet 1 para classificar cada atividade:

| Atividade | Pode ir para agente? | Nível de autoridade do agente | Agente sugerido |
|-----------|---------------------|-------------------------------|-----------------|
| | S / N / Parcial | Draft / Executa / Decide | |
| | S / N / Parcial | Draft / Executa / Decide | |
| | S / N / Parcial | Draft / Executa / Decide | |
| | S / N / Parcial | Draft / Executa / Decide | |
| | S / N / Parcial | Draft / Executa / Decide | |
| | S / N / Parcial | Draft / Executa / Decide | |

**Níveis de autoridade explicados:**
- **Draft** — Agente produz rascunho, você revisa e aprova antes de qualquer ação
- **Executa** — Agente executa a tarefa completa, você recebe o resultado
- **Decide** — Agente toma decisões dentro de parâmetros definidos (ex: selecionar qual template usar)

> Regra de ouro: comece com **Draft** para todas as atividades novas. Só eleve o nível depois de testar.
