# SITE$ — Módulo de Habilidade

> **Parte do RUNA SYSTEMS** — não vendido separadamente via funil
> Ativado após o alicerce quando o gargalo do cliente é presença web e landing pages que convertem
> Agente entregue: PIXEL (site neural com copy integrada à oferta)

## Quando Ativar

Cliente completa o alicerce (Claude Code → Sincronia → MIND$ → SQUAD$) e o principal gargalo identificado é:
- Ausência de página de vendas para o produto principal
- Landing page genérica sem conexão com o posicionamento real
- Dependência de freelancers para atualizações simples
- Incapacidade de iterar copy + design rapidamente

## Entregáveis do Módulo

- **PIXEL** — Agente neural de site: briefing → copy → estrutura → deploy — via AIOX + Stitch + Netlify
- Sistema de landing page com seções canônicas (hero, mecanismo, prova, oferta, FAQ, CTA)
- Capacidade de iterar sem agência — o cliente atualiza via Claude Code
