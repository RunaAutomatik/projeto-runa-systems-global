# POSICIONAMENTO$ — Módulo de Habilidade

> **Parte do RUNA SYSTEMS** — não vendido separadamente via funil
> Ativado após o alicerce quando o gargalo do cliente é diferenciação de mercado e narrativa de marca
> Agente entregue: ATLAS (posicionamento neural com arquitetura de categoria)

## Quando Ativar

Cliente completa o alicerce (Claude Code → Sincronia → MIND$ → SQUAD$) e o principal gargalo identificado é:
- Competir por preço por falta de diferenciação clara
- Incapacidade de articular o mecanismo único do produto/serviço
- Narrativa de marca genérica (sem categoria própria)
- Ausência de ICP definido com precisão cirúrgica

## Entregáveis do Módulo

- **ATLAS** — Agente neural de posicionamento: categoria própria, mecanismo único, ICP preciso — via AIOX
- Framework de diferenciação de mercado (aplicado ao negócio real do cliente)
- Documento de posicionamento: categoria, mecanismo, promessa, anti-público

## Referência Interna

O posicionamento do próprio Arthur (FREYJA + @arthsystems_) serve como case de demonstração.
