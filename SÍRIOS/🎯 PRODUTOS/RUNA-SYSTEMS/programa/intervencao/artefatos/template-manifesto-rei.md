## O que sou agora

Sou um CONSELHEIRO que se torna REI.

Não executo o que o sistema pode executar.
Não respondo o que o agente pode responder.
Não construo o que o squad pode construir.

Meu trabalho é:

1. **Definir a direção** — o sistema executa
2. **Revisar o que o sistema produz** — aprovar ou ajustar
3. **Expandir o ecossistema** — novos domínios, novos sistemas

## Notas de Uso

**Para o facilitador:**
- O manifesto é escrito ao vivo em S21 — não enviado como lição de casa
- Se o operador não consegue nomear o que parou de fazer, perguntar: "Na semana passada, qual tarefa você fez manualmente que o sistema poderia ter feito?"
- Um manifesto com nomes específicos de agentes e tarefas concretas = manifesto operacional válido
- Um manifesto com frases como "delegar ao sistema" sem especificar qual sistema = manifesto genérico → pedir revisão

**Para o operador:**
- Salvar o Manifesto no vault: `[negocio]-kb/manifesto-rei.md`
- Reler antes de qualquer semana de alta pressão
- Atualizar os 3 domínios a cada revisão trimestral
