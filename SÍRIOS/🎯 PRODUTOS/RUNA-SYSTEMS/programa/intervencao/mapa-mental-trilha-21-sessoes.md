# Mapa Mental — Trilha RUNA das 21 Sessões

> **Formatos:** INTERVENÇÃO (21 dias · 1 sessão/dia) · MENTORIA (60 dias · 1 sessão/semana)
> O conteúdo é idêntico. A diferença é densidade de entrega.

---

## Visão Geral da Jornada

```
👤 Cliente entra
     │
     ▼
🗺️  FASE 1 — FUNDAÇÃO (S01)
     │   Mapeamento Neural · Título: EXPLORADOR
     │
     ▼
🔨  FASE 2 — †CODE (S02–S03)
     │   Ambiente + Fluxo · Título: FERREIRO
     │
     ▼
🏗️  FASE 3 — SQUAD$ (S04–S06)
     │   Arquitetura + Agentes + Deploy · Título: CONSTRUTOR
     │
     ▼
🧠  FASE 4 — MIND$ (S07–S08)
     │   Base de Conhecimento + Memória · Título: ESTRATEGISTA
     │
     ▼
⚔️  FASE 5 — ESPECIALIZAÇÃO (S09–S17) ← 9 de 12 sessões (personalizadas em S01)
     │
     ├── TRACK A: Criador / Agência de Conteúdo
     │   A1 · A2 · A3 · A4
     │
     ├── TRACK B: Consultor / Mentor
     │   B1 · B2 · B3 · B4
     │
     └── TRACK C: Agência / Operações
         C1 · C2 · C3 · C4
     │
     ▼  Título: ESPECIALISTA (ao concluir as 9 sessões)
     │
     ▼
🎯  FASE 6 — INTEGRAÇÃO (S18–S20)
     │   Orquestração Total + Monetização Neural + Autonomia · Título: CONSELHEIRO
     │
     ▼
👑  SESSÃO FINAL — AUTONOMIA TOTAL (S21)
        Soberania Neural · Título: REI
```

## Progressão de Títulos (Sistema RPG)

| Sessão | Título | Símbolo | Significado |
|--------|--------|---------|-------------|
| S01 | EXPLORADOR | 🗺️ | Mapeou o terreno. Sabe onde está. |
| S03 | FERREIRO | 🔨 | Forjou as ferramentas. O ambiente obedece. |
| S06 | CONSTRUTOR | 🏗️ | Construiu o squad. A execução existe. |
| S08 | ESTRATEGISTA | 🧠 | Deu inteligência ao squad. O sistema sabe. |
| S17 | ESPECIALISTA | ⚔️ | Domina o nicho de operação neural. |
| S20 | CONSELHEIRO | 🎯 | Opera sem executar. Orienta o sistema. |
| S21 | REI | 👑 | Soberania neural total. Ensina e expande. |

## Fase 1 — FUNDAÇÃO

### S01 — Mapeamento Neural
> Sessão obrigatória para todos · 90–120 min

```
S01: MAPEAMENTO NEURAL
│
├── Block 1: Framing — por que mapear antes de automatizar
├── Block 2: Os 3 Níveis (L0 Estratégico / L1 Tático / L2–L3 Operacional)
├── Block 3: Tarefas vs Microtarefas (o átomo do processo)
├── Block 4: As 4 Categorias de Execução
│   ├── Agente Completo (Tarefas D)
│   ├── Híbrido (Humano + IA)
│   ├── Worker / Script
│   └── Humano Insubstituível
├── Block 5: Casos Reais (âncora de crença)
└── Block 6: Plano de Ataque + Revelação do Mapa (névoa levanta → S09–S17 reveladas)

DESAFIO: 10 tarefas categorizadas + 3 processos em L2 + setor prioritário identificado
ARTEFATOS: Worksheet 1A · Worksheet 1B · Worksheet 2 · Plano de Ataque · Mapa da Névoa
```

## Fase 2 — †CODE

### S02 — †CODE I: Ambiente
> Instalar e operar o terminal neural · 75–90 min

```
S02: AMBIENTE
│
├── Block 1: Framing — Chat vs Execução Agêntica
├── Block 2: Os 3 Ambientes Claude (Chat / Projects / Claude Code)
├── Block 3: Instalação (Node.js → npm install → claude --version)
├── Block 4: Core Tools — Demo ao Vivo com documento real
│   ├── Read   → lê qualquer arquivo
│   ├── Write  → cria arquivo novo
│   ├── Edit   → modifica cirurgicamente
│   ├── Bash   → terminal direto
│   ├── Grep   → busca em arquivos
│   └── Glob   → encontra arquivos por padrão
├── Block 5: Primeiro Teste Real (cliente executa sozinho)
└── Block 6: DESAFIO + próxima sessão

DESAFIO: Claude Code instalado + documento real analisado + processo documentado
ARTEFATOS: Checklist de Instalação · Guia Permission Modes · Cheat Sheet Ferramentas
```

→ Doc completo: [[runa-intervencao-sessao-02-tcode-ambiente]]

### S03 — †CODE II: Fluxo
> Configurar o ambiente que conhece o negócio · 75–90 min

```
S03: FLUXO
│
├── Block 1: Framing — Agente genérico vs agente do negócio
├── Block 2: Anatomia do CLAUDE.md (5 Camadas)
│   ├── Camada 1: Identidade
│   ├── Camada 2: Regras de Comportamento
│   ├── Camada 3: Contexto do Negócio
│   ├── Camada 4: Comandos e Workflows
│   └── Camada 5: Ferramentas e Ambiente
├── Block 3: Construção do CLAUDE.md do Cliente (ao vivo, 5 passos)
├── Block 4: Settings.json (permission mode, modelo, hooks básicos)
├── Block 5: Primeiro Agente Simples (.md com persona + comandos)
└── Block 6: DESAFIO + desbloqueio do título FERREIRO

DESAFIO: CLAUDE.md com 3 regras reais + agente ativo + 5 tarefas executadas
ARTEFATOS: CLAUDE.md Base · Settings.json · Template Agente Simples · Guia Comandos
🔨 TÍTULO DESBLOQUEADO: FERREIRO
```

→ Doc completo: [[runa-intervencao-sessao-03-tcode-fluxo]]

## Fase 3 — SQUAD$

### S04 — SQUAD$ I: Arquitetura
```
Identificar 3–5 agentes core · Criar .yaml de cada · CLAUDE.md do squad com matriz de delegação
DESAFIO: 3 agentes com .yaml completo + escopos distintos sem overlap
```

### S05 — SQUAD$ II: Agentes
```
Ativar e testar cada agente em cenário real · Primeiro handoff entre agentes
DESAFIO: Tarefa real usando 2 agentes em handoff — artefato entregue
```

### S06 — SQUAD$ III: Deploy
```
Hooks pre/post-tool · Primeiro worker · Integração com 1–2 ferramentas externas
DESAFIO: Processo rodando 48h consecutivas com log de operação
🏗️ TÍTULO DESBLOQUEADO: CONSTRUTOR
```

## Fase 4 — MIND$

### S07 — MIND$ I: Base de Conhecimento
```
Framework Universal de Extração · Template Master · Vault AKASHA personalizado
DESAFIO: 5 documentos estruturados + squad responde 3 perguntas consultando a base
```

### S08 — MIND$ II: Memória e Evolução

```
Memory.md por agente · Protocolo semanal de atualização KB · 5 prompts de consulta core

🧠 TÍTULO DESBLOQUEADO: ESTRATEGISTA
```

## Fase 5 — ESPECIALIZAÇÃO (Pool de 12 · Cliente seleciona 9)

> Reveladas ao final de S01. A ordem é personalizada para cada cliente.

### TRACK A — Criador / Agência de Conteúdo
```
A1 · CREATOR$ I    — Sistema de conteúdo com agentes (pipeline completo)
A2 · CREATOR$ II   — Automação de publicação (scheduling + repurposing)
A3 · †COWORK I     — Claude.ai Projects como co-criador (entregáveis longos)
A4 · †COWORK II    — Chat + Code integrados (pipeline editorial autônomo)
```

### TRACK B — Consultor / Mentor
```
B1 · †CHAT I           — Atendimento neural (primeiro nível + escalação)
B2 · †CHAT II          — Qualificação e diagnóstico neural de prospects
B3 · POSICIONAMENTO$ I — Diferenciação (pitch + tagline + manifesto)
B4 · POSICIONAMENTO$ II — Autoridade e escassez (banco de provas)
```

### TRACK C — Agência / Operações
```
C1 · SITE$          — Landing page neural (copy + build + deploy)
C2 · Automações I   — n8n: triggers e fluxos básicos (3 automações)
C3 · Automações II  — CRM e follow-up neural (sequências de onboarding)
C4 · ORÇAMENTO$     — Proposta e precificação neural (3 propostas reais)
```

> ⚔️ **TÍTULO DESBLOQUEADO: ESPECIALISTA** — ao concluir as 9 sessões escolhidas

---

## Fase 6 — INTEGRAÇÃO

### S18 — Integração I: Orquestração Total
```
Unir squad + KB + automações + especialização · Command Center funcional
DESAFIO: Todos os sistemas sem silos + relatório semanal gerado pelo ecossistema
```

### S19 — Integração II: Monetização Neural
```
Inventário do ecossistema → oferta → stack replicável → primeiro pitch
DESAFIO: Oferta estruturada + pitch para cliente ou parceiro real
```

### S20 — Integração III: Autonomia Operacional
```
Protocolos de health-check · Alertas automáticos · Plano de evolução trimestral
DESAFIO: 72h de operação autônoma + relatório gerado pelo squad
🎯 TÍTULO DESBLOQUEADO: CONSELHEIRO
```
