## Recomendação: Primeiro Squad = Criação

**Por quê Criação e não Atendimento?**

Atendimento tem 43h, mas Gabriel disse que seu atendimento pessoal é *"mais atencioso e acolhedor"* e *"fundamental"*. Ele não quer largar o volante ali — quer ser o comandante. Isso é mais complexo de implementar como primeiro squad.

Criação tem:
- 130h/semana de volume
- Visão clara de delegação
- Baixo risco (cliente aprova antes de publicar)
- ROI imediato visível

**Squad de Criação — Composição sugerida:**

```
Copy Agent       → recebe briefing do cliente → gera copy de feed → Draft para aprovação
Design Agent     → recebe briefing + brand kit → gera arte → Executa (editável)
Video Agent      → recebe roteiro/tema → gera vídeo/reels → Executa
Calendar Agent   → recebe demandas do mês → monta cronograma → Draft para aprovação
Brand Agent      → recebe briefing de IV → estudo + conceito + assets → Executa
```

**Configuração central necessária:**
Cada cliente da Pesto precisa de um **Brand Kit** no sistema:
- Fonte(s) aprovadas
- Paleta de cores
- Estilo visual
- Tom de voz / copy guideline

Esse brand kit é o contexto L2 que alimenta todos os agentes de criação.

## Pontos para Aprofundar na Sessão

### 1. Os "clones" (mencionado no Worksheet 2)
Gabriel quer geração de vídeo com "clones" — provavelmente talking heads ou avatares dos clientes. Perguntar:
- São avatares dos próprios clientes (que precisam de fotos/vídeos de treino)?
- São avatares de personagens/mascotes das marcas?
- Ou avatares do próprio Gabriel para conteúdo da Pesto?

### 2. A questão das fontes por cliente
Cada cliente tem família de fontes própria. Isso é uma restrição técnica real — confirmar:
- Fontes ficam no Wix/Canva dos clientes hoje?
- Têm arquivos .ttf/.otf centralizados?
- Licenciamento está resolvido?

### 3. Escala da equipe
246h é equipe. Antes de montar o squad, mapear:
- Quantas pessoas hoje?
- Quem faz o quê? (não precisa de nomes — só função)
- Alguma delas seria "gerente" do squad em vez do próprio Gabriel?

### 4. OPUS-like (corte automático de vídeos)
Ele quer algo como Opus Clip. Confirmar:
- Os vídeos longos são gravações de clientes (podcasts, entrevistas)?
- Ou são gravações da própria Pesto?
- Volume semanal de vídeos longos para cortar?

### 5. Atendimento como Commander
A visão do Gabriel para atendimento é sofisticada:
> *"ele avalie cenários de respostas [...] e proponha ações que podem ser realizadas. E depois eu dou o comando para outros agentes executarem a estratégia"*

Isso é o modelo Commander do $QUAD. Não é Sessão 02 — é talvez Sessão 04 ou 05. Mas vale validar na Sessão 01 que ele entende que isso vem depois, não agora.
