  AS FERRAMENTAS QUE VAMOS USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Nenhuma ferramenta é obrigatória.
A lógica é transferível — se uma ferramenta mudar, o método continua o mesmo.


─────────────────────────────────────────────────
  VISÃO GERAL DO STACK
─────────────────────────────────────────────────

  ● Nano Banana Pro    →  Geração de imagens (Passo 1)
                          Plano gratuito: créditos diários
                          nanobananapro.com

  ● Higgsfield         →  Hack da pintura → input para vídeo (Passo 2)
                          Plano gratuito: créditos disponíveis
                          higgsfield.ai

  ● Sora 2             →  Geração de vídeo ultra-realista (Passo 3)
                          Acesso via Opera + VPS (instruções no Módulo 3)
                          sora.com

  ● vmake.ai           →  Remover marca d'água do vídeo
                          Plano gratuito: upload automático
                          vmake.ai

  ● LENS (GPT)         →  Otimizar prompts de imagem antes de gerar
                          Gratuito com conta ChatGPT

  ● REEL (GPT)         →  Gerar prompts narrativos para o Sora 2
                          Gratuito com conta ChatGPT


─────────────────────────────────────────────────
  NANO BANANA PRO
─────────────────────────────────────────────────

O que faz: gera imagens a partir de prompts de texto.
Ótimo para criar a imagem base do avatar.

Alternativa: o próprio Higgsfield também gera imagens —
use se preferir centralizar em uma única ferramenta.

Versão gratuita: créditos diários renovam automaticamente.
Para o volume deste curso, o plano gratuito é suficiente.


─────────────────────────────────────────────────
  HIGGSFIELD
─────────────────────────────────────────────────

Duas funções no nosso método:

  1. Gerar a imagem base do avatar
     (alternativa ao Nano Banana Pro)

  2. Aplicar o hack da pintura ultra-realista
     (obrigatório antes de ir para o Sora 2)

Por que é essencial: o hack do Módulo 3 — transformar a imagem
em pintura com traços de tinta — só funciona no Higgsfield.
Esse passo é o que garante movimento natural no vídeo.


─────────────────────────────────────────────────
  SORA 2
─────────────────────────────────────────────────

O que faz: gera vídeos de 15 segundos a partir de
imagem + prompt. É a ferramenta que transforma a imagem
do seu avatar em vídeo ultra-realista.

Acesso no Brasil: o Sora 2 não está disponível diretamente.
→ Instruções completas de acesso estão no Módulo 3.


─────────────────────────────────────────────────
  VMAKE.AI
─────────────────────────────────────────────────

O que faz: remove a marca d'água do Sora 2 automaticamente.
Upload do vídeo → processamento automático → download limpo.

Quando usar: após selecionar o melhor take no Sora 2.


─────────────────────────────────────────────────
  AGENTES INCLUÍDOS NO CREATOR$
─────────────────────────────────────────────────

  ★ LENS — Diretor de Imagem

  Otimiza o seu prompt antes de gerar qualquer imagem.
  Você descreve o avatar, ele estrutura o prompt no
  formato correto para o Nano Banana Pro.

  Acesso:
  https://chatgpt.com/g/g-69be9c381dcc81919e85d56ace38c9f4-lens-r


  ★ REEL — Diretor de Vídeo

  Gera o prompt narrativo para o Sora 2.
  Você descreve o que quer que o avatar faça no vídeo,
  ele entrega o prompt completo pronto para colar.

  Acesso:
  https://chatgpt.com/g/g-69bebdb35f748191952d6500f350c386-reel-r
