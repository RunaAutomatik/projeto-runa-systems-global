# Memória e Evolução do Sistema

> MIND$ · Sessão S08

Um squad estático é um squad que envelhece. O que diferencia um sistema que dura 5 anos de um que fica obsoleto em 6 meses é o protocolo de atualização. Esta sessão define como o seu sistema aprende.

---

## As Três Camadas de Memória

| Camada | Onde fica | O que armazena | Cadência |
|--------|-----------|----------------|---------|
| **Operacional** | `.claude/memory/` | Preferências, decisões recentes, contexto ativo | Toda sessão |
| **Estrutural** | Vault (Obsidian) | Specs, decisões, entregáveis, referências | Semanal |
| **Histórica** | GitHub (commits) | Configurações versionadas, decisões com contexto | Por mudança relevante |

---

## Protocolo Semanal de Atualização

→ [`artefatos/protocolo-atualizacao-semanal-kb.md`](artefatos/protocolo-atualizacao-semanal-kb.md)

**Todo domingo (ou início de semana), execute:**

1. **Revisão da base** — o que o squad gerou esta semana que merece ser preservado?
2. **Ingestão** — alguma fonte nova merece entrar no AKASHA?
3. **Calibração** — algum agente precisa de ajuste com base no uso desta semana?
4. **Commit** — versionar as mudanças no GitHub

**Tempo total:** 20–30 minutos por semana.

---

## Como os Agentes Aprendem

Os agentes não aprendem sozinhos — você alimenta o aprendizado deles com:

1. **Exemplos de sucesso:** "Esse output foi perfeito, salva como referência"
2. **Correções:** "Não faça X — faça Y porque..."
3. **Novos contextos:** "Agora também atendo [novo nicho] — ajuste o escopo"
4. **Insights de mercado:** Ingestão periódica de novas referências no AKASHA

O arquivo de memória de cada agente captura o que foi aprendido:
→ [`../artefatos/template-memory-agente.md`](../artefatos/template-memory-agente.md)

---

## Sinais de que o Sistema Está Evoluindo

✅ Os agentes respondem mais rápido e com menos reorientação
✅ O vault tem novos documentos toda semana
✅ O AKASHA tem novas páginas no wiki com frequência
✅ Os commits do GitHub mostram refinamentos consistentes
✅ Você passa menos tempo explicando contexto e mais tempo direcionando

---

## Sinais de que o Sistema Está Estagnando

❌ Os agentes sempre precisam ser reorientados da mesma forma
❌ O vault não cresce há semanas
❌ As calibrações são as mesmas toda vez
❌ Você está fazendo manual o que o squad deveria fazer

Quando identificar estagnação, volte ao protocolo semanal e execute uma sessão de manutenção.
