# MODULO ESPECIALIZAÇÃO — Índice

> As trilhas S09–S21. O cliente escolhe uma trilha na S01 e aprofunda nela.
> Sessões: S09–S21 (13 sessões de especialização)

---

## Diagnóstico de Trilha (Output da S01)

A trilha é diagnosticada na S01 com base no perfil do negócio:

| Trilha | Para quem | Foco principal |
|--------|-----------|---------------|
| **Track A — Creator** | Criadores de conteúdo, influencers, educators | Conteúdo, audiência, monetização via comunidade |
| **Track B — Conversão** | Consultores, mentores, agências de serviço | Proposta, funil, fechamento high-ticket |
| **Track C — Automação** | Agências técnicas, SaaS, negócios com operação complexa | n8n, workers, pipelines, escala sem time |

**Critério de seleção:**
- Qual é a maior alavanca do negócio agora?
- Onde está o maior gargalo de crescimento?
- Qual trilha entrega resultado mais rápido para este perfil?

O mentor registra a decisão em `MENTORADOS/{cliente}/02-diagnostico-trilha.md`.
