# Artefato — Template Mapa da Landing Page

> **Usado em:** Track C1 — Block 2 (Exercício de Mapeamento ao vivo)
> **Onde salvar:** No vault do operador ou preencher diretamente durante a sessão.
> **Como usar:** Preencher antes de ativar o agente-copy. O mapa é o briefing do agente.

---

## Por que mapear antes de escrever

O mapa não é o copy — é o blueprint.
Quando o agente-copy recebe um vault bem estruturado, ele gera texto específico.
Quando recebe um vault vago, gera copy genérico.
O mapa garante que o operador articule o que sabe antes de delegar ao agente.

## Checklist de Aprovação do Mapa

Antes de passar o mapa para o agente-copy, verificar:

| Critério | ✅/❌ |
|---------|-------|
| ICP está nomeado de forma específica (não "empreendedores") | — |
| Problema central está na voz do ICP (não na voz do consultor) | — |
| Causa ataca uma lógica equivocada, não um concorrente | — |
| Mecanismo tem nome próprio (não "consultoria personalizada") | — |
| Prova tem pelo menos 1 número e 1 prazo | — |
| Próximo passo está claro em 1 frase | — |
| CTA tem texto específico (não "saiba mais" ou "clique aqui") | — |

**Mínimo 6/7 para passar para o agente-copy.**
Se algum critério falhou: preencher o campo correspondente antes de prosseguir.

## Após o Mapeamento

```
1. Mapa aprovado (≥6/7) → copiar conteúdo para os arquivos vault:
   - icp.md ← campos das seções 1, 2, 3
   - metodo.md ← campos das seções 1, 4
   - casos.md ← campos da seção 5

2. Ativar o agente-copy:
   *headline "landing page principal"
   → escolher 2 variações para A/B

3. Gerar seção por seção ou:
   *pagina-completa --format=html

4. Fazer download do index.html
5. Arrastar para netlify.com/drop
6. Testar: CTA funciona? Link abre?
7. Copiar URL — página no ar
```
