## Product Overview

**Family name:** RUNA SYSTEMS — Reestruturação Universal Neural Adaptativa
**Category:** High-ticket AI business mentorship
**Tagline:** *Você não está faltando tempo. Está faltando arquitetura.*

RUNA SYSTEMS teaches business owners how to restructure their operation using AI — not by replacing the human, but by making the human work less and reach more. It is not a software product. It is a reconstruction of how a person operates a business.

The product family has three delivery tiers, identical in content, differentiated by support intensity and delivery speed.

---

## The Big Idea

Most people approach AI tools the way they approach Google — as a search engine. They ask questions, copy the answer, move on. Nothing changes structurally.

RUNA SYSTEMS operates from a different premise: **the human is the main executor.** One of four executor types working in symbiosis:

| Executor Type | Role | Characteristics |
|--------------|------|-----------------|
| **Human** | Main executor — indispensable | Strategic judgment, relationships, creative decisions |
| **Neural agents** | Reasoning + creative autonomy | Domain experts with full context and voice |
| **Tool agents** | Specific objective, hybrid execution | LLM + deterministic logic, no creative freedom |
| **Hooks / workers / scripts** | Automation layer | Triggered, no reasoning, high volume |

The anti-myth at the core: *"press button, business runs itself"* does not exist. What changes is that the human works with higher quality, higher reach, and lower manual load — because the architecture handles the mechanical layer.

**Body metaphor (curriculum anchor):**
- Tools = hands
- Second Brain + Squad = skeleton + brain
- Modules = muscles, organs, arteries
- The human = the being that animates all of it

## ICP — Ideal Client Profile

### Primary ICP
Small communication and marketing agency owners:
- Social media managers
- Branding agencies
- Traffic managers
- Web designers / web agencies

**Profile characteristics:**
- 5–50 clients, operating solo or with small team
- Overwhelmed by execution: everything passes through them
- Cannot delegate because there is no documented process
- Working IN the business, not ON it
- Technically curious but not developer-level
- Revenue: R$10k–R$80k/month
- Pain: unsustainable operation — more clients = more chaos, not more money

**Reference case — Lucas Pesto:**
Agency owner, 33 clients, estimated 246h/week required before restructuring.
Needed: delegation infrastructure, not tool education.
Built: full squad with orchestrator + specialist agents, mapped business processes, Obsidian second brain.

### Secondary ICP
- Consultants and mentors scaling their knowledge delivery
- Creators building content systems
- Solo operators in any knowledge-based business

### NOT for
- Employees wanting to be more productive at work
- Businesses with no documented process (first 0→1 needs to happen manually)
- Anyone looking for a "done-for-you" that replaces their thinking entirely

## Delivery Model

### What RUNA SYSTEMS is NOT
- Pre-recorded video lessons (knowledge lives in live sessions)
- A done-for-you agency (human remains the main executor)
- A generic AI tools course (curriculum is hyper-personalized)

### What it IS
- Live sessions where knowledge is transferred in real time
- Documents that serve as KB + agent training data (not video summaries)
- A structured path that adapts to each client's business context
- Symbiotic learning: while the client learns, AI simultaneously builds context for their business

### Hyper-personalization rule
No two clients receive the same curriculum order. Path is determined at Session 01 (business mapping). Modules are unlocked progressively based on the client's specific operational bottlenecks.

## CREATOR$ Module — Full Content Map

**What the client builds:** An AI avatar with consistent image library + video capability.

**Tools used:**
| Tool | Function | Cost |
|------|---------|------|
| Nano Banana Pro | Image generation from prompts | Free (daily credits) |
| Higgsfield | Image base generation + painting hack for video | Free plan available |
| Sora 2 | 15-second ultra-realistic video generation | Via Opera + VPS (BR access workaround) |
| VMake | Watermark removal | Free |

**Agents included:**
- **LENS** (GPT) — image prompt optimizer for Nano Banana Pro style
- **REEL** (GPT) — narrative video prompt generator for Sora 2

**Module structure:**

| Lesson | Content |
|--------|---------|
| Caixa de Ferramentas | Tool stack overview, LENS + REEL setup |
| Construindo a Personagem | Character identity worksheet (name, backstory, transformation, values, appearance, voice) |
| Storyboard | 6-block permanent avatar document |
| Prompt Master // Fotos | 6-block prompt structure; Lo-Fi realism rules; LENS workflow |
| Biblioteca Visual | Image curation (30–40 generated → 20–30 approved); seed management |
| Hack Sora 2 // Vídeos | Painting hack (Higgsfield → Sora 2); REEL workflow; 3-take selection |
| Biblioteca de Formatos | Format specs for all platforms (Reels, Stories, Feed, YouTube Shorts) |
| Storybook Final | Consolidated permanent reference document |
| Prompt Pack | Organized prompts: Portraits (P-01–05), Scenarios (S-01–03), Expressions (E-01–05), Looks (L-01–02), Video (V-01–03) |
| Guia Rápido | 4-step method reference; agents quick access; selection criteria |

**Critical method insight:**
> Roupa em detalhes = consistência no vídeo.
> The Higgsfield painting hack is what allows Sora 2 to animate without changing the face.
> NEGATIVE block in every prompt prevents studio lighting contamination.
