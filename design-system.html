fa-faq

What fonts does this design system use?

Two Google Fonts: Roboto Mono (weights 400–700) for headings, labels, and all monospace UI; Montserrat (weights 300–700) for body copy and lead paragraphs.

How are design tokens structured?

All tokens live in :root as CSS custom properties prefixed --ais- for brand values and --bg-, --fg-, --grad-, --glow- for semantic aliases.

Is there a naming convention for components?

Yes — a BEM-like pattern with the fa- prefix for main components: .fa-hero, .fa-feature, .fa-quote, etc. Sub-elements use the double-underscore pattern: .fa-hero__title, .fa-feature__icon.
