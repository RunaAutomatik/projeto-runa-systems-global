# Conversão Comment-to-Checkout

The 5-step conversion framework for @arthsystems_: from Instagram post comment to product checkout, with upsell to Runa Systems Method.

## The 5-Step Flow

```
1. POST
   └─► Caption with CTA keyword ("comente ARQUITETO")

2. COMMENT
   └─► Person comments the keyword

3. DM TRIGGER (Zernio API — HERMES)
   └─► Automated DM fires immediately
         └─► Message: acknowledgment + link to Offer Doc

4. OFFER DOC
   ├─► Structured persuasive copy (FREYJA writes)
   ├─► Entregável (deliverable)
   │     ├─► 80% case: PAID — R$19,90–29,90 micro-product
   │     └─► 20% case: FREE — prompt, checklist, or 1-page roadmap
   └─► Checkout button → specific $ product

5. INSIDE $ PRODUCT
   └─► Upgrade suggestion → Runa Systems Method (gravado/intervenção/mentoria)
```

## 80/20 Entregável Rule

| Type | When | Price |
|------|------|-------|
| Paid | Deliverable has structure, design, or meaningful effort | R$19,90–29,90 |
| Free | Prompt, simple checklist, or 1-pager with no friction barrier | R$0 |

**The entregável must be the exact entry point for the $ product being sold.**
It shows WHAT. The $ product shows HOW. That gap IS the sale.

## FREYJA Protocol

For every post with a keyword CTA, FREYJA must specify:
1. Entregável name
2. Type (paid/free) + price
3. Why it sells the next product (the logical gap it creates)
4. $ product at checkout
5. Upsell inside the $ product to Runa Systems Method
